# Seven Online v2

Adds:
- Login and registration
- Secure password hashing with bcrypt
- HTTP-only JWT login cookie
- PostgreSQL persistence
- Multiplayer Elo rating
- Tier system
- Global leaderboard
- Match history
- Player profile
- Basic room reconnection after browser refresh

The core Seven rules from v1 are preserved.

See `DEPLOY.md` for Railway setup.
